Conditions Générales d'Utilisation

Dernière mise à jour : 18 août 2026

1. Objet

Les présentes Conditions Générales d'Utilisation (« CGU ») régissent l'utilisation de l'application mobile Skaneo (« l'Application »), disponible sur Android. En installant ou en utilisant l'Application, vous acceptez sans réserve les présentes CGU.

2. Description du service

Skaneo est une application qui permet, entièrement hors ligne :

  • de scanner une ou plusieurs cartes de recharge (Yas, Orange, Airtel) via la caméra ou une photo importée depuis la galerie ;
  • de détecter automatiquement l'opérateur et de générer le code USSD correspondant ;
  • de générer un code USSD de retrait Mobile Money, tous opérateurs, à partir d'un numéro destinataire et d'un montant saisis par l'utilisateur ;
  • d'utiliser l'application en français ou en malgache.

3. Rôle et limites de Skaneo

Skaneo est un outil de lecture (OCR) et de génération de codes USSD. L'Application ne traite, ne stocke et ne transmet aucun fonds. Elle n'est ni un opérateur téléphonique, ni un établissement financier, ni un intermédiaire de paiement. Une fois le code USSD généré, la transaction (recharge ou retrait Mobile Money) est exécutée exclusivement par le réseau de l'opérateur concerné (Yas, Orange ou Airtel), en dehors du contrôle de Skaneo.

4. Retrait Mobile Money responsabilité de l'utilisateur

Pour la fonctionnalité de retrait Mobile Money, l'utilisateur saisit lui-même le numéro destinataire et le montant. Il est de la seule responsabilité de l'utilisateur de vérifier l'exactitude de ces informations avant de valider la composition du code USSD. Skaneo ne peut être tenu responsable d'une erreur de saisie, d'un envoi à un mauvais destinataire, d'un échec de transaction côté opérateur, ou de toute conséquence financière résultant de l'utilisation de cette fonctionnalité.

5. Scan, multi-scan et import de photo

La reconnaissance OCR peut, dans de rares cas, mal lire un code en raison d'un éclairage insuffisant, d'une carte endommagée ou d'une photo de mauvaise qualité. Il appartient à l'utilisateur de vérifier le code affiché avant de composer le code USSD généré. Skaneo décline toute responsabilité en cas d'erreur de lecture non détectée par l'utilisateur.

6. Conditions d'utilisation

L'utilisation de Skaneo est réservée à un usage personnel et licite. Il est interdit d'utiliser l'Application à des fins frauduleuses, notamment pour générer des transactions Mobile Money sans le consentement du titulaire du compte concerné. L'utilisateur doit être majeur ou disposer de l'autorisation d'un représentant légal pour utiliser l'Application.

7. Permissions de l'application

Skaneo demande l'accès à la caméra et, le cas échéant, à la galerie photo, uniquement dans le but de lire les cartes de recharge. Aucune image n'est envoyée sur internet : tout le traitement OCR se fait localement sur l'appareil de l'utilisateur.
